# AIVA Group — NFC-визитка

Одностраничная визитка для NFC-карты (NTAG215). Без сборки, чистый HTML.

## Файлы
- `index.html` — сама страница
- `contact.vcf` — контакт для кнопки «Сохранить контакт» (с логотипом)
- `vercel.json` — правильный тип файла для .vcf и кэш
- `logo.svg`, `icon-192.png`, `apple-touch-icon.png`, `og.jpg` — логотип, иконки и превью для мессенджеров

## Публикация
1. Создайте репозиторий на GitHub и загрузите все файлы .
2. Vercel → Add New → Project → выберите репозиторий → Deploy (настройки не нужны).
3. Рекомендуется свой поддомен: Vercel → Settings → Domains → `aiva-card.vercel.app`,
   у регистратора добавить CNAME `card` → `cname.vercel-dns.com`.
4. После этого в `index.html` замените `content="og.jpg"` на полный адрес
   `https://aiva-card.vercel.app/og.jpg` — так превью будет показываться в Telegram.
5. Если адрес визитки другой (не aiva-card.vercel.app), поменяйте `CARD_URL` в `index.html`.
   На опубликованном сайте QR-код и «Поделиться» сами берут текущий адрес,
   CARD_URL нужен только для предпросмотра файла с телефона.

## Как работают кнопки
- «Сохранить контакт»: на iPhone (Safari) сразу открывается карточка «Новый контакт».
  На Android скачивается файл AIVA-Group.vcf, после нажатия на него телефон предлагает сохранить контакт.
  Работает на опубликованном сайте (https), а не в файле, открытом из Telegram.
- «Поделиться визиткой»: QR-код на адрес визитки, «Отправить» открывает системное меню
  «Поделиться» (или Telegram, если меню недоступно), «Скопировать» копирует ссылку.

## Запись на карту
NFC Tools → Запись → Добавить запись → URL → вставить адрес → Записать → приложить карту.

## Как поменять данные
- Телефон/Telegram/Instagram: в `index.html` (блок «Связаться») и в `contact.vcf`.
- Услуги и цены: массив `services` в конце `index.html`.
